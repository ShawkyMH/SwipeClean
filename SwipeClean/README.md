# 📱 تطبيق SwipeClean - دليل الاستخدام والتشغيل

تطبيق أندرويد متكامل يعمل كمعرض وسائط ذكي (صور وفيديوهات) مع واجهة تنظيف وسائط سريعة بأسلوب السحب (Swipe).

---

## ✨ المميزات المضافة والمنفذة

1. **إيماءات السحب التفاعلية (Swipe Gestures)**:
   - **سحب لليمين (Swipe Right)**: الاحتفاظ بالصورة أو الفيديو وتخطيها.
   - **سحب لليسار (Swipe Left)**: حذف الصورة أو الفيديو من ذاكرة الهاتف مع مراعاة أذونات الأمان (Scoped Storage).
   - توفير أزرار تحكم سريعة (Check / Delete) بديلة لسهولة الاستخدام بيد واحدة.

2. **🔍 فلترة الوسائط حسب النوع**:
   - شريط تصنيف علوي: (الكل / صور 📷 / فيديو 🎬).

3. **📁 تصفح وفلترة حسب المجلدات (Albums / Folders)**:
   - قائمة منسدلة تسرد جميع المجلدات الموجودة على الجهاز (الكاميرا، الواتساب، التنزيلات، لقطات الشاشة، إلخ).

4. **↩️ التراجع السريع عن الحذف (Undo)**:
   - شريط تنبيه سفلي (Snackbar) يظهر فور الحذف مع زر "تراجع ↩️" لاسترجاع الملف مباشرة في حال كان الحذف بالخطأ.

5. **🖼️ واجهة المعرض الكامل (Gallery View)**:
   - شبكة منظمة (Grid) تعرض جميع عناصر الوسائط مع شارة مدة الفيديو وحجم الملفات وزر للرجوع السريع.

2. اختر **Open** ثم توجّه إلى المسار:

4. وصّل هاتفك الأندرويد عبر الـ USB (مع تفعيل خيار USB Debugging) أو شغّل محاكي (Emulator).
5. اضغط على زر **Run** ▶️ لتثبيت التطبيق على الجهاز.
